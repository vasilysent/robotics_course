# Fundamentals of Robot Kinematics and Dynamics

This repository contains materials I developed for a master's course on robot kinematics and dynamics, which I co-taught at the University of Twente with [Stefano Stramigioli](https://people.utwente.nl/s.stramigioli?tab=overview) and [Federico Califano](https://people.utwente.nl/f.califano). Starting from first principles, the course develops the main results of the theory with full conceptual and technical rigour, using the modern language of differential geometry.

The centrepiece of the course is the [lecture notes](notes.pdf). They are complemented by a practical [assignment](assignment/), in which students complete a Python library for the kinematics and control of serial-chain robots and implement geometric wrench control for a trajectory-tracking task with a UR5e robot arm simulated in MuJoCo.

## Course outline

**I. Mathematical Foundations**

1. Sets, Maps and Notation
2. Linear Algebra
3. Groups and Manifolds

**II. Kinematics**

4. Euclidean Spaces and Rigid Motion
5. Rigid Body Velocity
6. Kinematics of Serial Robots

**III. Dynamics**

7. Rigid Body Dynamics
8. Dynamics of Serial Robots
